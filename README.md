This repository consists of a README.md file that contains a summary of information needed for Assignment 2, ENGG680 F2026, Group 20.
## Introduction to Lab Assignment 2
This assignment introduces students to using machine learning applications in python with using real applicable data from GNSS and accelerometer and movement data. Students learned how to perform nonlinear least squares, gradient descent, and classification using support vector machine. This assignment as been split into two parts, which each has four and three subsections, respectively. The first part of the project focuses primarily on using nonlinear least squares and gradient descent to estimate position of a GNSS receiver. The second part of the project involves motion classification with inertial sensor data on a training/testing dataset followed by testing on two other individual datasets. We learned how to apply python function including pandas, numpy, matplotlib, and various machine learning imports including sklearn. Throughout this assignment, we were required to apply our knowledge about statistics and various machine learning models to real observations as well as explain our findings and evaluate our models.

## Part 2
Part 2 involved classification using support vector machine (SVM) in order to perform motion classification using inertial sensor data on two individual testing datasets and then evaluating the model. The first section of part 2 involved using all features excluding the target vector (which was motion state) in the training and testing of the model before it was tested on the two independent datasets. The second section involved using pre-selected features to test the data, and finally the third section of the data used features that were selected by the group and then tested on the data. Section one required us to load all of the datasets into dataframes and then perform a grid search with cross validation, with the target vector being stored in the y variable and all other features being stored in the X variable. The dataset was then split into training/validation and testing sets, which then required us to use train_test_split from sklearn. A pipeline was initialized using a scaler and a classifier followed by a definition of a grid search configuration for hyper parameter tuning of the support vector classifier. The model was then evaluated by printing a confusion matrix and classification report to visualize the results and allow us to comment on the overall fit of the model to the training model and to the two independent testing sets. Using this step-by-step process, we applied this to the second and third section, however the X variables consisted selected features for the second and third section in order to evaluate the models differently.
